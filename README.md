# 抖映

给旧安卓电视使用的抖音网页客户端。电视自带的旧网页引擎播放抖音视频时会在几秒后崩溃，抖映把较新的网页引擎放进应用里，不再使用电视系统自带的网页引擎。

当前版本：1.1

## 遥控器

- 上下键：切换视频
- 确认键：播放或暂停
- 菜单键：在上下键模式和光标模式之间切换
- 光标模式：方向键移动白点，确认键点击
- 返回键：弹出退出提示，再按确认退出

打开应用后会自动进入网页播放器的全屏状态。关闭登录框后，如果尚未全屏，会继续自动点击全屏。全屏后自动打开底部的连播开关。

左侧栏只保留精选、推荐和我的，隐藏 AI抖音、朋友、关注、直播、放映厅、短剧和小游戏。

## 说明

这不是抖音官方应用。抖音网页可能会要求登录、弹出验证，或因网页改版影响操作。1.1 不隐藏登录框，避免留下灰色遮罩。

安装包只包含 32 位 ARMv7 引擎，已在 TCL 65V2、Android 9 上验证打开、全屏和遥控器操作。其他型号需要自行测试。

## 构建

使用 Android SDK、JDK 11 或更高版本，在 gecko-test 目录执行：

```text
gradlew assembleDebug
```

调试安装包位于：

```text
gecko-test/app/build/outputs/apk/debug/app-debug.apk
```

网页引擎组件较大，不放进源码仓库。构建前把适配目标处理器的 GeckoView 128.0.20240725162350 AAR 放到 gecko-test/app/libs/geckoview-armv7.aar。
